# Beat to Track: The 11-Word Game Hub

A focused classroom game hub for **Oxford Discover Futures 4, Unit 1**.

## Target vocabulary

`beat` · `genre` · `hit` · `lyric` · `melody` · `pitch` · `playlist` · `rhythm` · `soundtrack` · `tempo` · `track`

## Included games

1. **Vocabulary Rush** — definitions and associations
2. **Word Decoder** — spelling and one-word recall
3. **Conceptual Links** — meaning and association matching
4. **Studio Clash** — team sentence construction
5. **WordLab Jeopardy** — mixed teacher-led review

Every assessed answer comes from the same eleven-word set. The site is a self-contained static page and requires no build command.

## Deployment

Connect this repository to Netlify. The included `netlify.toml` publishes the repository root.
